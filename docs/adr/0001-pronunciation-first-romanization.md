# Pronunciation-first romanization instead of Revised Romanization

Expressions are displayed primarily in a pronunciation-first romanization, split by syllable with hyphens. It uses Revised Romanization letter values but spells what is actually said: 맥주 → *maek-jju* (RR: *maekju*), 학교 → *hak-kkyo* (RR: *hakgyo*), 얼마예요 → *eol-ma-e-yo*. The learner's goal is to say things out loud within weeks, not to read signs, so the spelling must match what is spoken. Keeping RR letter values (g/k, d/t, b/p) keeps words recognisable on signs and keeps plain and aspirated consonants distinct. The cost: spellings won't exactly match the official Revised Romanization, and every Expression in the Catalog is authored this way, so switching later means re-authoring the whole Catalog. Across word spaces, only obligatory sound changes join words (못 해요 → *mo-tae-yo*); optional linking keeps words apart (색 있어요 → *saek i-sseo-yo*) so the learned word stays recognisable. The full conventions are in the header of `catalog/catalog.ts`.
